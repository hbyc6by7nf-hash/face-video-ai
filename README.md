# Face Video — репозиторий для Claude Code

Проект для создания версии **приложенного** видео с вашим лицом у главного героя и лицом друга вместо головы робота на заднем плане.

## Что делать (самый простой способ)
1. Распакуйте ZIP и откройте папку `face-video-repository` в Claude Code.
2. Положите **ваше** фото в `input/me.jpg`, фото друга (с разрешения друга) — в `input/friend.jpg`.
3. В чате Claude Code напишите: `Прочитай CLAUDE.md и README.md. Настрой окружение, покажи превью и создай видео. Если нет модели или FFmpeg, объясни что установить.`

Исходное видео уже находится в `input/reference.mp4`.

## Запуск вручную
Нужны Python 3.10/3.11 и FFmpeg в PATH.

Для быстрого теста лица друга:
```
python -m pip install -r requirements-preview.txt
python src/make_video.py --friend input/friend.jpg --skip-main-face --preview-time 2.5 --out output/preview.jpg
```

Для полного ролика нужны зависимости AI и лицензированная совместимая модель `models/inswapper_128.onnx`:
```
python -m pip install -r requirements.txt
python src/make_video.py --me input/me.jpg --friend input/friend.jpg --out output/result.mp4
```

Параметр `--provider cuda` доступен, если в окружении установлен совместимый ONNX Runtime GPU.

## Что действительно умеет код
- Главный герой: нейросетевая подмена лица моделью INSwapper при наличии весов.
- Друг: **2D-наложение** фотографии на область шлема по ключевым кадрам с мягкой маской (не нейросетевая генерация нового тела/лица).
- Исходный звук при обработке всего ролика копируется в финальный MP4 через FFmpeg (кодируется AAC).
- Результат сохраняется в `output/`.

Координаты друга заданы в `SETTINGS` в `src/make_video.py`, подобраны под исходное видео 908×512. При необходимости их можно настроить.

Модель INSwapper **не вложена в репозиторий**; проверяйте правила использования и лицензию выбранных моделей. InsightFace pretrained models могут быть ограничены некоммерческим исследовательским использованием.

Пользуйтесь фото с согласия людей; не представляйте AI-видео как настоящую запись.
