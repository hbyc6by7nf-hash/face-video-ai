# AI-редактор видео: ваше лицо у главного героя, лицо друга вместо робота

Программа берёт оригинальное видео и две фотографии и создаёт MP4, в котором:

* у **главного героя** лицо заменено на ваше с помощью нейросети (INSwapper + GFPGAN);
* **голова робота на заднем плане** (≈1.0–3.5 с) заменена головой друга, которая следует за шлемом;
* движения, ракурсы, монтаж, эффекты и **оригинальный звук** сохраняются (аудио копируется без перекодирования).

Есть веб-интерфейс: три поля загрузки и кнопка **«Создать видео»**.

## Установка

Нужны Python 3.10+ и FFmpeg (`ffmpeg` и `ffprobe` в PATH).

```bash
python -m pip install -r requirements.txt
python scripts/download_models.py --accept-noncommercial   # ~1.2 ГБ моделей в models/
```

Флаг `--accept-noncommercial` — подтверждение, что вы прочитали лицензию InsightFace (см. ниже).

## Запуск

**Интерфейс:**
```bash
python app.py        # откроется http://127.0.0.1:7860
```
Загрузите видео, свою фотографию и фотографию друга → «Создать видео». Результат сохраняется в `output/result_<дата>.mp4`
и доступен для скачивания. Кнопка «Превью кадра» быстро показывает один кадр; в разделе «Друг вместо головы робота»
можно поправить рамку шлема (кнопка «Показать рамку»), время, яркость, наклон и размер.

**Командная строка:**
```bash
# превью одного кадра (сек.)
python run.py --me input/me.png --friend input/friend.png --preview-time 2.5 --out output/preview.jpg
# полный ролик
python run.py --me input/me.png --friend input/friend.png --out output/result.mp4
# быстрее, без GFPGAN; другая рамка шлема (доли кадра x y w h в момент --friend-anchor)
python run.py --me me.jpg --friend friend.jpg --no-enhance --friend-box 0.11 0.30 0.20 0.52 --friend-anchor 2.5
```
`python run.py --help` — все параметры.

## Как это устроено

```
app.py / run.py
src/facevideo/
  models.py     ONNX-обёртки: SCRFD, ArcFace, INSwapper, GFPGAN, BiSeNet (без пакета insightface)
  align.py      шаблоны выравнивания, аффинные преобразования, смешивание, перенос цвета (Lab)
  main_face.py  замена лица главного героя + временная стабилизация
  friend.py     трекинг шлема и вставка головы друга
  pipeline.py   два прохода: анализ → рендер; FFmpeg с оригинальным звуком
  video.py      чтение, детектор монтажных склеек, запись MP4
scripts/download_models.py
```

**Главный герой (нейросетевая замена):**
1. Проход анализа: в каждом кадре SCRFD находит лица, ArcFace считает эмбеддинги; герой выбирается **по личности**
   (кластер самых крупных лиц), поэтому фигурки и фоновые лица не трогаются.
2. Пропуски детекции (смаз, вспышка) до 6 кадров заполняются интерполяцией; ключевые точки сглаживаются
   фильтром без задержки фазы внутри каждого плана (не через склейки) → нет дрожания и мерцания.
3. Рендер: выравнивание → INSwapper 128 → GFPGAN 512 (детали) с сохранением низкочастотного освещения сцены →
   подстройка тона кожи под исходный кадр (Lab) → маска лица BiSeNet по **исходному** кадру, поэтому руки,
   пистолет, нож и т.п. перед лицом остаются поверх → мягкое смешивание, маска сглажена по времени.
   Повороты головы, мимика и освещение берутся из исходного видео — модель меняет только идентичность.

**Друг вместо робота (2D-композит, не нейросетевая замена):**
у робота нет человеческого лица, поэтому ни один face-swap-движок его не «увидит». Голова друга вырезается
нейросетевой сегментацией (лицо, уши, волосы, шапка), отслеживается за шлемом оптическим потоком
(KLT + RANSAC, сдвиг/масштаб/наклон, сглаживание), перекрашивается под тон кожи героя в том же плане,
затемняется, получает свет/тени области шлема, размытие под глубину резкости и шум плёнки. Появление/исчезновение —
по монтажной склейке либо плавно.

## Честно об ограничениях

* Замена главного лица — настоящая нейросетевая подмена, но INSwapper работает в 128 px: на очень крупных планах
  GFPGAN дорисовывает детали. Причёска, борода по контуру, форма головы остаются от актёра — модель меняет
  черты лица, а не голову целиком. При сильных профилях, смазе и перекрытиях результат слабее.
* **Голова друга не поворачивается и не говорит** — это фото, перемещаемое вместе со шлемом. Оно выглядит
  как вставка, а не как живой человек. Это не выдаётся за фотореалистичную замену.
* Для более реалистичного друга нужна генеративная анимация головы: например, LivePortrait (оживление фото
  по движению «водителя») + отдельная маска шлема (SAM 2) + видео-к-видео модели (коммерческие API вроде
  Runway / Kling / Wan VACE). Это требует GPU с 12–24 ГБ VRAM или платного API и отдельной проверки лицензий.
* Производительность: на CPU (4 ядра) около 2–3 с на кадр с GFPGAN; 11-секундный ролик — ~10–12 минут.
  С NVIDIA GPU (`pip install onnxruntime-gpu`, `--device cuda`) — в 10–20 раз быстрее.
